The drawings

From Dynamo to C#

At Trinam Design I wrote each automation twice. First as a Dynamo graph, to prove the idea on a real model: window-module tagging and automatic dimensioning were the first ones. Dynamo was usually too slow at the scale the drafters needed, so I rewrote the tools as C# add-ins on the Revit API and gave them their own tab on the Revit ribbon, grouped by the work they do (paneling, detailing, shop drawings, fabrication, state and QC).

  • C# add-ins for dimensioning, numbering, elevations and views, with WPF windows for the controls.
  • Projects set up for both the Revit 2023 and the Revit 2025 APIs.
  • Used day to day by a dozen drafters, checked by hand against real project files with screenshots of the results.
  • Outside the job, IFC4 export code in my own projects, so the open-format side of BIM is familiar ground.
